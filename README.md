# 🐱 MeowMind Clone

Клон Telegram-бота для управления чатами: экономика, модерация, кэпы,
интерактивные списки, магазин, игры/опросы, кастомные команды + веб-панель.

## Возможности

- **Экономика** — баллы, топ, нормы (глобальные и по группам), группы участников, приставки, сезоны, канал с баллами.
- **Модерация** — варны (авто-бан на 3), мут/размут (5м/2ч/1д), кик, бан/разбан, история наказаний.
- **Кэпы** — расширенные модераторы с гибкими правами (кнопки), режимы `только_кепы` и `передача_баллов`.
- **Списки** — интерактивные наборы с `{user}`/`{cap}`, места занимаются кнопками, лимит кэпов.
- **Магазин** — товары авто (бот выполняет) и ручные (пишет админу), покупка за баллы.
- **Игры/опросы** — расписание с напоминаниями (APScheduler), шаблоны опросов.
- **Кастомные команды** — `+кмнд` с текстом/медиа/кнопками-ссылками, подстановки, алиасы.
- **Авто-регистрация** — пользователи попадают в БД при первом сообщении (без userbot).
- **Веб-панель** — FastAPI на localhost: чаты, участники, баллы, товары.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # затем впишите BOT_TOKEN и OWNER_ID
```

Узнать свой `OWNER_ID`: напишите @userinfobot в Telegram.

## Запуск

```bash
.venv/bin/python main.py
```

Бот и веб-панель стартуют вместе. Панель: http://127.0.0.1:8080
(логин/пароль из `.env`, по умолчанию admin/admin).

## Команды

Полный список — команда `.помощь` в чате с ботом.

## Структура

```
main.py              — точка входа (бот + веб + планировщик)
config.py            — настройки из .env
database/            — модели и сессия SQLAlchemy (SQLite)
handlers/            — хендлеры команд по модулям
services/            — бизнес-логика (economy, moderation, caps, ...)
keyboards/           — inline-клавиатуры
middlewares/         — авто-регистрация пользователей
utils/               — парсинг цели/времени/даты, фильтры команд
web/                 — FastAPI-панель + шаблоны
```

## Заметки

- База — SQLite (`meowmind.db`), создаётся автоматически. Для продакшена
  можно переключить `DATABASE_URL` на PostgreSQL.
- Команды используют префиксы `.` `+` `-` (как в оригинале), не `/`.
- Зайди в бота @BotFather -  /setprivacy выбери своего и нажми на  Disable
- Все делал Opus 4.8 + Sonnet 4.6.
